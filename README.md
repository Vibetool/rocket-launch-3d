# 火箭发射 3D 版

独立的 Three.js / Blender 实验版。原版：https://vibetool.github.io/rocket-launch/

本版本从原版提交 `60214a9e873f73437cad3e43a41c0bd2c0748c46` 复制，`parts.js`、`physics.js`、`game.js` 保持原样，通过 `three-view.js` 替换渲染。没有修改原版仓库或数据库结构。

## 操作

- 主页点击制造大楼开始装配，雷达站载入机库记录和标准三级火箭。
- 鼠标拖动 / 单指拖动旋转，滚轮 / 双指捏合缩放；装配时右键拖动平移。
- 发射、分级、卡门线继续飞行和月面点火使用原版按钮与空格操作。
- 局内双击实际发射台或塔架：本局推力 +40%，蓝紫尾焰。地形不触发。
- 重置视角恢复构图；省电画质关闭阴影并降低渲染分辨率。

## 保持一致的规则

引擎推力 30/20/15，燃料容量 100/60/20；100 km 卡门线，当前原版的 105 km 月球触发线；月面从 1 km 开始，燃料恢复至保留级满载的 30%，重力为地球 2/3，安全着陆 16 m/s。返回舱、分离器、继续飞行的速度继承沿用原版。

本机存档键前缀独立为 `rocket3d_`。现有云端机库与双人联机信令地址沿用 `config.js`；可用性取决于原有后端部署、WebRTC 网络与麦克风权限。本项目不包含服务器迁移、不修改线上数据库。联机逻辑与原版相同，未新增 TURN 服务。

## 模型与构建

`assets/rocket-models.blend` 是可在 Blender 中继续编辑的原始工程，`rocket-models.glb` 是浏览器使用的模型包。模型由 `tools/build_models.py` 生成，包括八种火箭部件及制造大楼、雷达站、发射塔架。无 AI 图片 API 或密钥依赖。

```sh
npm ci
npm run vendor
npm test
node tools/browser-test.mjs
```

浏览器测试用 Chrome，自行启动随机端口临时服务，在测试期间拦截后端请求，避免污染线上机库；另通过两个真实 WebRTC 数据通道验证装配门禁、设计同步、双人发射及自动分级（本地交换 SDP，不写线上信令）。截图写到系统临时目录。GitHub Pages 直接发布 main 根目录；无需常驻本地服务器。Three.js 固定版本 vendored，许可证见 `vendor/THREE-LICENSE.txt`。

2026-09-06 只读接口检查：`ships.php?limit=1` 返回 200；当前配置的 `room.php?action=status` 返回 404。因此线上建房/邀请还需要恢复现有信令接口，不能把本地 P2P 测试通过视为线上联机已可用。

## 兼容性

需要 WebGL 2 与 ES Modules。提供不支持/模型加载失败提示和 2D 版链接。Chrome 桌面及触屏尺寸模拟可自动验收；安卓实机、微信内核、跨网络双人语音仍需真实设备验收，不能用桌面模拟替代。
